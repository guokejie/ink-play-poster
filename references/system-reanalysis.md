# 九图系统复审

本轮再次打开九张全图；原素材及内置图可访问。重点是将视觉观察转换成选案与失败判断，而非增加风格词。

|原图|设计决策|原图证据|失败信号|
|---|---|---|---|
|P01|负形锚定|巨形实黑与弯臂白区配重|负形被纹理填满导致手杯读不清|
|P02|闭环读序|上弧、人物、下字闭合|装饰与衣纹同权重抢焦点|
|P03|斜势框架|臂/杯斜向，侧字沿外轮廓|顶底都加重字造成中心挤压|
|P04|错落连续|标题行与壶/滤杯竖向串联|文字等距后断开动势|
|P05|场景分层|角色—桌线—前杯相叠|仅剩孤立动物失去操作关系|
|P06|双锚运动|上黑标题与下动作相呼应|标题/人物两团间留空槽|
|P07|宽窄编辑|宽刊头+窄字+多臂向上承接|字全放大后信息失去层级|
|P08|细节内聚|杯竖纹/碟椭圆增强体量|纹理多于轮廓，器物身份模糊|
|P09|字物咬合|大壶和环圈字占彼此余隙|文字缩成普通顶部标题|

逐图密度、空间、图文、层次和背景详见composition.md；字形/排版详见typography.md。真实共性仍是黑墨与白底，但背景的结构作用和密度各异；没有证据要求所有图都加渐变/全幅图案。新增模块化网格和重复组合属于有条件的设计扩展，不能伪称九图共同特征。
