# 设计决策系统 v4

每次读此页。保留composition_plan和type_plan，增加decision和product_contract，避免继续累积没有执行顺序的形容词。

## 观察 → 识别 → 三案 → 选择 → 出图 → 证据评估 → 定向修复
1. 查看相关原图；参考不可访问时说明缺失，不以旧总结冒充本轮观察。用户只要局部修改时锁定已批准构图，不强制重设计；新海报至少构思三个结构不同的方案。
2. 食品先定义product_contract：名称、身份特征、轮廓/体量、表面/截面、易混对象、不可牺牲部位。原图有实物依据时优先原图；仅主题时不虚构具体配料/认证。一般原型见products.json，只作结构常识，不代替实际SKU证据。
3. decision.candidates至少三案，每案记录id、family、anchor、reading_path、spatial_relation、reference_basis、risk、scores。family可为偏置词团、对角动作、图文咬合、编辑网格、局部裁切、重复组合等；至少三个不同family，不可用换色/换字号充数。每案必须改变锚点、读序或字物空间关系中的至少两项。仅有题材不同不算新构图。
4. scores各0–2：identity（识别）、reference（参考依据）、hierarchy（层级）、interaction（图文）、novelty（与近期结构差异）。分数是取舍记录，不是美学客观值；必须同时写risk和选案reason。identity或reference为0的方案不选；不是机械取最高总分，用户目标/可读性优先。选案写selected，额外方案不直接传图像模型。
5. 完成选中案的composition_plan/type_plan（含typography.md的整组轮廓、笔画逻辑、光学字距、产品呼应与重量分配），给出主/次/背景/信息的职责和读序。无文案不编副文案；背景可白，但需结构角色。网格/重复若超出原图直接依据，明确属于兼容探索而非原图共性，默认优先有原图依据的方案。
6. 使用 `python scripts/prompt.py brief.json --ready --out prompt.txt`。--ready会拦截缺少决策/产品合同/空间字体方案的生产提示词；不带--ready可生成诊断草稿，不能跳过决策直接调用图像工具。用户无字海报可以省type_plan，必须explicit exact_text=[]且mode=art-only，空间方案不能保留空标题槽。
7. 真实查看结果后填写qa.json，再运行 `python scripts/review.py qa.json`。工具仅检查记录和分流，不自动看图、不执行OCR。任何关键识别错误/文本错误不因总体好看放行；每轮处理最严重的1–2项。

## 产品识别与艺术化
结构优先于表面纹理。菠萝包要能读为圆拱酥皮面包，不是菠萝水果、龟壳、足球或可颂卷纹；皮层纹理是有体量的断裂块，不是满幅随机划痕。可颂弯月和卷层必须同时保留；蛋挞的开放壳口/馅心/层叠壳边优先，焦斑不能遮满馅心。允许夸张比例，不允许缩略后只能靠文字辨认食品。

## 中英标题适配
中文：先保护部件拓扑、偏旁位置与关键笔画，再改横纵比例、局部重量和行形；不能随机斜切拉伸每笔，不能用拉丁连笔替代汉字。英文：通过x-height/大写高度、字宽、字腔、连字和光学字距创造节奏；完整词读序优先，不能吞字母。双语：先决定主次，再选共享特征（端点、倾角、宽窄或笔触其中1–2项），不是随意拼两种字。长信息使用清楚排字，与标题共享一个形态线索即可。

## 背景和层次的选择顺序
先关系层：接触、遮挡、负形、轴线与尺度；再重量层：黑块/中空、粗细、主次字；再语义辅助层：必要器具、动作线、局部结构重复。背景色/图案只在参考或明确方向支持时引入；本组原图不支持默认渐变或全幅复杂图案。每项新增元素写“删掉会损失什么”，答不出则删。不是每张都要人物、托盘、桌线或三维前中后景。

## 评估与修复映射
qa.json dimensions含八项，每项rating 0/1/2、evidence（实际看到的现象）、action。产品和文本两项硬门槛另由gates字段记录：product、text、structure各pass/fail/unknown。unknown不能当通过。八项：product,composition,title,interaction,hierarchy,support,style,finish。
- product失败：先简化纹理，恢复轮廓/皮馅边界，锁定其他设计；必要时参考用户实物。
- composition失败：改锚点、读序与关系，选择第二候选，不仅增大或加纹理。
- title失败：修字形/字距，复用底图；强交错画面用前后层或编辑，不矩形覆盖。
- interaction失败：重设字与物的接触/共用轮廓，不加小图标。
- hierarchy失败：减少同权重焦点，改线面与尺度对比，不能加更多元素。
- support失败：删无用物或赋予语义作用；style失败回到原图对应轴。
- finish失败：修裁切、边缘、字错、粘连，核对最终导出。
两次同类修复仍无改善，换构图/分层方法并标记局限，不无限重复生成。反馈为局部调整时尊重锁定范围。商业完成度是对可读、识别、工艺和交付的判断，不是承诺商业表现或宣称已完成印刷适配。

## 字体质量门槛 v5
依据typography.md补齐七项type_review；“有手写感/错位”不能替代审美证据。文本正确与字形美感分别检查。只有明确无字成图且text_absent=true可省type_review，不能用它绕过有字海报检查。

## 产品世界 v6
每次产品创作按product-world.md建立association_plan，发散候选但仅将选中元素和关系注入模型；--ready会检查依据与连接，qa按world_review评估真实叙事。用户单品限制优先。字体v5整组轮廓机制保留，不以额外弧线/装饰替代字形流动。

## 通用创意与选角 v7
按creative-association.md建立creative_plan；--ready同时检查主题理解、隐喻、选角、一致性、克制理由。角色可选，世界关系由实际选案决定。world_review包含casting_fit，共五项。
