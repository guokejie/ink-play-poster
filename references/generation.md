# 提示词与可靠文字工作流

## brief 输入协议
`scripts/prompt.py` 只依赖 Python 3 标准库，生成适用于不同图像模型的自然语言底稿。必须先由代理理解用户，不依赖关键词脚本猜测语义。字段：

```json
{
  "topic": "书店周末阅读",
  "exact_text": ["周末读书会", "慢慢读，慢慢聊"],
  "styles": ["P05"],
  "format": "3:4 vertical, target 1536 x 2048",
  "subject": "圆耳原创小动物坐在桌边翻开一本大书，杯子为次要道具",
  "layout": "主体略偏右，左上保留两行标题区，底部短句，避免复制原图居中店牌",
  "audience": "社区读者",
  "use": "社交媒体",
  "mode": "art-only",
  "text_zones": "依照composition_plan与type_plan定位，不固定上下空槽",
  "constraints": "不出现咖啡品牌、日期、地址"
}
```

相对 Skill 根目录执行：`python scripts/prompt.py brief.json --out prompt.txt`。未指定styles时脚本仅以P08作兜底；实际使用应先做语义选择。脚本不读取图片、不生成图片、不负责排字，提示词需代理检查后传给实际图像工具。

## 完整提示词的推理顺序
目的与受众 → 视觉隐喻和新动作 → 主风格的线条/黑块/笔触 → 新版空间结构 → 调色 → 字体层级 → 原文白名单 → 输出比例 → 不希望出现的内容。给模型可观察的形式要求，比如“中空轮廓、黑鼻与杯两处实黑、桌线偏低”，不要仅写“高级、艺术感、参考风格”。若无负面提示词参数，把限制写进主提示词。

图像参考：调用前查看选定的1–2张参考，告诉工具它们只约束视觉语言，用户的产品图只约束产品识别。编辑时区分最新成图和风格图，明确哪些区域改变。模型不支持参考路径时以文字描述继续，披露还原能力限制。

## 文字分流和修复
1. 先按typography.md做信息精简与字号节奏设计，再建立 exact_text 白名单；白名单保存最终获准上版的内容，不把所有联想出的口号一并加入。用户明确指定的原文不擅删。建立 exact_text 白名单：把用户明确要上版的每条文字原样保存。参考图的品牌、日期与签名永远不是白名单来源。用户图片内需要转录的文字先辨认；模糊关键数字请用户确认。缺少日期就省略，不能用参考日期填补。
2. 短字允许画面文字一体生成。打开结果放大逐字检查，可用OCR作辅助但不能仅凭OCR认定正确。检查汉字偏旁、标点、大小写、日期、是否有额外伪字。保存实际看到的文字、与白名单差异及修复结果。
3. 需要精确的中文长文/活动信息，或一次局部改字失败：直接生成无字底图，把标题与信息区的大小和位置写清楚。不要在含错字的底图上叠字；先编辑去除错字并确认背景干净。
4. 用可用的本地排版工具（Pillow、SVG浏览器渲染或设计工具）添加确定性文字层。文字数据直接取exact_text，不重新手输。先枚举真实存在的字体，选支持全部字符的字体；不以缺字方框交付。标题用可读圆润/手写字体，信息用规整字体；不对地址数字加粗糙滤镜。轻微位置变化只能辅助排布节奏，不能替代手写字形设计；若备用字体无法还原选定风格，记录并披露限制，不以文字正确声称手写风格通过。
5. 用字形测量自动换行，溢出先增加文本区或调布局，再适当减字号；不能裁字、改词或省略。数字海报的信息字建议在1080px宽输出中至少约24px，实际以缩至展示大小仍可读为准。保留可编辑SVG或排字源文件，再导出PNG。SVG有外部底图或字体依赖时应嵌入或连同依赖打包，不能只交空壳链接。
6. 打开最终合成图复检：100%查字与边缘，缩略图查层级；只验证文本层字符串不等于验证最终显示。中文没有可用字体/渲染工具时明确说明并交付无字底图和文字规范，不把待排版文件称为完成海报。

## qa.md 记录
记录版本、主辅风格、原文数组、最终文字逐条通过/未通过、视觉检查（笔触/黑白重量/构图/主体辨识/留白）、修改内容与剩余问题。风格各项可评0–2分：0偏离，1部分一致，2清楚一致；这只是主观诊断而非客观相似度。任何文字错误或识别结构错误都需修复，不用总分抵消。每轮不超过两次盲目重试；仍失败改分层或报告具体依赖，不无限消耗生成资源。

## 精细还原
局部参考、标题独立生成、合成命令和融合轴约束见 [production.md](production.md)。两张风格输入必须有aux_axes；例如P06+P02只借色填写 `["palette"]`。

## 字体创意前置（更新）
每次调用必须按typography.md建立type_plan；短文案也不例外。prompt.py会把完整字段注入提示词，缺省只给风格语法和补齐提示，不代表已完成设计。无字底图按type_plan预留位置，不再固定上下空白。精确文本仍由exact_text唯一控制。

## 密度与空间前置
每次按composition.md补齐composition_plan，与type_plan共同决定画面。白底可保持，但需写出主体占幅、遮挡层次、语义辅助物与空区用途。没有副文案时重组空间，不保留固定上下空槽，不以编造信息补空。

## 生产门槛 v4
生产提示词必须用--ready，验证decision、product_contract、composition_plan与type_plan；脚本只传选中候选，落选方案保留在brief供复盘，避免图像模型混合三种布局。没有--ready的旧命令仅为诊断草稿。

## 产品世界 v6
每次产品创作按product-world.md建立association_plan，发散候选但仅将选中元素和关系注入模型；--ready会检查依据与连接，qa按world_review评估真实叙事。用户单品限制优先。字体v5整组轮廓机制保留，不以额外弧线/装饰替代字形流动。

## 通用创意与选角 v7
按creative-association.md建立creative_plan；--ready同时检查主题理解、隐喻、选角、一致性、克制理由。角色可选，世界关系由实际选案决定。world_review包含casting_fit，共五项。
